## About me

I've been shipping websites, e-commerce stores and web applications on open-source stacks for **15+ years**, starting in 2010. I work with agencies, brands and startups to build custom Shopify apps and themes, WordPress sites and plugins, Laravel back ends and React front ends, from first commit to production.

Most of my work lives in **private client repositories**, so what you see on my public profile is only the tip of the iceberg. The repos in my account alone span 70+ projects, and they are a small slice of everything I've delivered since 2010.

## What I build

| Area | What that looks like |
|---|---|
| 🛍️ **Shopify apps** | Embedded admin apps and extension-only apps: product swatches, bundle discounts, product sliders and cards, XML product feeds, SEO and image alt-text tools. Built with Node.js, Laravel + Shopify API, Polaris, App Bridge and GraphQL. |
| 🎨 **Shopify themes** | Custom Online Store 2.0 themes and heavy customisations of premium themes, campaign and sale landing pages, Liquid sections and blocks. |

| ⚙️ **Laravel platforms** | SaaS-style apps with JWT / Sanctum APIs, admin portals and user portals: greenhouse-gas emissions reporting, a digital life-vault, an affiliate marketplace, trail mapping and a trading platform. Twilio, CSV import / export, Guzzle integrations. |
| ⚛️ **React / TypeScript front ends** | Vite + React + TypeScript + Tailwind + shadcn/ui dashboards and SPAs, and a Dockerised Google Business Profile management app (Laravel API + React). |

| 🤖 **Automation & AI** | AI chatbots, content-generation pipelines and Kubernetes cluster scaling scripts for batch workloads. |
